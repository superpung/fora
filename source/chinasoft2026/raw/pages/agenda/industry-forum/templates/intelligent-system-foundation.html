智能系统底座与应用实践论坛

工业论坛 I8

一、论坛介绍

随着人工智能技术向产业场景深入应用，智能系统的创新正从模型能力拓展走向计算架构、基础软件、数据语义与应用反馈的协同演进。如何打通芯片、算力、操作系统和数据支撑之间的技术链路，形成开放、高效、可持续演进的系统底座，已成为推动智能应用落地的重要议题。

本论坛邀请来自海光信息技术、腾讯云、航天信息、蚂蚁、紫光云及墨芯人工智能的专家学者，围绕国产算力支撑的具身智能、数据库自演进语义层、双反馈驱动的智能应用、AI操作系统和芯片软硬协同设计等主题，分享技术路线与产业实践，探讨智能系统从底层支撑到应用落地的关键挑战。

本论坛旨在促进产学研交流与合作，探索智能系统底座建设与应用创新的协同路径，推动相关技术成果向产业场景转化。

四、论坛报告嘉宾简介

1. 报告人：王子谋 海光信息政府与公众行业方案部副总经理

题目：安全与智能两翼齐飞，海光助力国产算力建设高质量发展

摘要：具身智能正从"硬件本体攻坚"迈向"大脑模型决胜"，算力芯片成为决定性的底层变量。然而高端训练与推理芯片受出口管制约束，封闭的全栈生态形成事实锁定，具身智能算力底座面临"卡脖子"与"被绑定"的双重困境。本报告聚焦于开放型国产化具身智能技术路线的解决方案分享，以自主 CPU 与 GPGPU 异构算力为底座，坚持"开放算力、开放模型、开放生态"三大原则——算力层兼容开放异构计算软件栈，模型层适配主流WAM、VLM、VLA等模型，生态层联合高校与产业链共建开放平台。报告将分享该路线在具身大模型国产化适配、训推一体化平台构建、行业场景验证等方面的实践成果，探讨以开放生态破解封闭锁定、以自主算力支撑智能体迈向物理世界的可行路径。

简介：王子谋先生现任海光信息技术有限公司 政府与公共行业方案部副总经理,主管交通医卫科研教育技术工作，以丰富行业经验带领海光产业生态大力投入交通行业数字化转型的解决方案打造及市场引领。此前，王子谋先生曾在深度参与交通、医疗、教育行业技术规划及算力建设咨询工作，拥有多年的IT产业从业经验，凭借前瞻的视野以及实践积累，致力于中国信息产业的自主可控与高质量发展。协助用户有效利用云、大数据、人工智能等IT新型态，创新商业模式，在产业数智化趋势下把握先机。

2. 报告人：张卿 高级工程师

题目：从 ATLAS 到 Nexa Knowledge：大规模数据库自演进语义层的研究与实践

摘要：企业级 Text-to-SQL 的难点，不仅在于生成 SQL，更在于让系统在海量库表中理解业务、跟上物理 Schema 的持续变化，并从使用中积累知识。本次分享将介绍从 ATLAS 研究原型到 Nexa Knowledge 企业级生产项目的演进，探讨如何构建面向大规模数据库的自演进语义层。我们将围绕语义上下文的自动生成与组织、面向大规模库表的自适应检索，以及 Schema 变更驱动的上下文维护，介绍研究思路与生产实践；进一步讨论自动生成、人工核准和使用反馈如何协同，在一致性、生成成本与服务可用性之间建立可落地的机制，让语义层从一次性的元数据补充，逐步成为与物理结构保持一致、持续积累业务理解的基础设施。

简介：张卿，复旦大学硕士，在腾讯云从事数据库语义层，NL2SQL，Agent Context 和 Ontology 的相关研究和开发工作。

3. 报告人：刘振宇 技术创新部副部长

题目：航天信息金税智能体系统底座与财税数智化升级实践专题分享

摘要：随着国务院《关于深入实施"人工智能+"行动的意见》落地推进，智能体正从对话工具演进为自主执行的行动主体，财税行业迎来从功能软件向智能伙伴转型的关键窗口期。本报告以航天信息金税智能体为实践载体，系统阐述面向财税领域的智能体系统底座建设思路与数智化升级落地经验。（分三部分展开：首先分析大模型技术演进趋势与财税行业数字化转型需求，阐明"优秀的模型底座 + 结合业务场景的模型调优 + 定制化场景应用开发缺一不可"的工程认知；其次重点介绍金税智能体的分层系统底座，包括"通用模型 + 专业模型 + 场景模型"三层模型架构，MaaS 平台与开发中心、知识中心、应用市场构成的平台工具层，以及检索增强（RAG）、多模态意图识别、多源聚合检索、安全对齐等核心技术；最后分享智能开票、智能记账、智能审核、智能申报、智能风控、合同智审等典型场景在集团企业、大中企业、小微企业及代账机构四类客群中的落地实践与量化成效，并结合"大模型只是 AI 链条一个环节"的思考，展望财税数智化的发展方向。）

简介：刘振宇，高级工程师，中国航天科工集团科技委人工智能专业组成员，北京市科学技术委员会评审委员，北京邮电大学人工智能学院企业导师，中关村科技园区管理委员会科技项目专家、目前任航天信息股份有限公司技术创新部副部长，牵头负责信诺财税大模型和金税智能体建设，带领团队完成“2+1+N”财税大模型体系建设和落地应用，累计服务用户超三百万户，发表人工智能领域高水平论文十余篇、专利百余篇，先后获得航天科工集团科技进步二等奖、自治区科技进步二等奖等省部级奖项。

4. 报告人：岳赟 高级算法专家

题目：双反馈驱动的蚂蚁阿福APP

摘要：面向 AI 诊室、报告解读、健康问答、就医服务和健康档案等应用场景，蚂蚁阿福通过构建“离线反馈优化模型、在线反馈实时纠偏”的双反馈体系，将用户反馈转化为模型持续改进的动力。离线反馈，让历史问题转化为模型改进。 阿福将历史问题案例、点赞点踩、好评差评等反馈进行归因，构建可训练样本，通过监督微调、强化学习和 MOPD 多目标优化，持续改善模型表现。整个流程贯通自动训练、质量验证、灰度部署和线上监控，并以原有能力不下降作为上线门槛，推动模型优化从实验走向业务服务。在线反馈，让用户诉求得到及时回应。 LiveSense 系统实时感知用户纠正、重复表达诉求及强烈不满等信号，定位理解偏差和上下文遗漏，通过动态系统提示修正后续回答。针对营销活动、业务规则变化等带来的突发问题，系统可通过反馈聚类、纠偏策略生成、自动评测和灰度发布快速响应。同时，新问题持续回流，推动负反馈识别模型与纠偏策略迭代，形成即时纠偏与长期学习相互促进的机制。

简介：蚂蚁阿福 Agent Infra 负责人

5. 报告人：柳义利 CTO、正高级工程师

题目：紫鸾AI操作系统产业创新与实践分享

摘要：产业私域生产AI落地的瓶颈不仅在模型能力，更在异构算力如何统一调度、私域数据如何转成可用知识、智能体如何在数据不出域约束下稳定执行。本次分享介绍紫鸾AI操作系统的设计与实践：算力层，多品牌国产GPU的统一纳管、池化切分与拓扑感知调度，配合RoCE参数面隔离，使MoE推理性能提升；推理层，通过权重与KV Cache量化分页、前缀复用与水位感知动态批处理，在显存、首Token时延与吞吐间进行优化；知识与智能体层，打通数据治理、知识加工与检索增强闭环，支撑工作流与自主规划等智能体范式，并以原生安全围栏覆盖提示词注入、数据投毒与算力耗尽等五类威胁。最后结合在芯片设计、工业设计、企业生产、医疗等产业实践，分享私有化部署中的工程取舍与待解问题。

简介：柳义利，毕业于西安电子科技大学，硕士研究生毕业，现任紫光云技术有限公司首席技术官CTO，在ICT行业深耕多年，有着丰富的产品研发、方案研发，产品管理和市场营销经验。2000年在华为，是第一台三层以太网交换机的开发者。2003，在华三，开创开创性地研发出新一代12500X-AF最高端旗舰产品，奠定了H3C在该领域领导者地位。2020年，担任新华三云智产线总经理，后兼任产品研发总经理。

6. 报告人：郭威俊 副总裁

题目：下一代国产芯片软硬协同设计及稀疏架构应用

摘要：大模型推理持续面临算力与存储带宽瓶颈，稀疏计算是提升国产AI芯片算力能效的关键路径。本报告结合墨芯软硬协同设计及稀疏架构技术实践，对比静态权重稀疏、动态激活稀疏两类技术路线，剖析稀疏硬件单元、数据寻址调度、软硬协同编译等核心技术难点；结合智算中心、生物信息等落地场景，分享稀疏计算产业实践与现存挑战，并探讨稀疏计算领域产学研协同创新路径。

简介：郭威俊先生现任墨芯人工智能集团市场及公关副总裁，统筹墨芯品牌及对外市场公关策略，负责协调深化墨芯科技品牌资产及品牌舆情口碑，曾任哈啰商业化平台总经理，全面负责哈啰营销系统及战略产品从0-1的搭建，对当下中国O2O营销市场有深刻洞察和前沿见解。在加入哈啰之前，历任腾讯社交与效果广告部全国快消行业负责人，在腾讯工作的9年时间里曾领导腾讯社交广告深度服务联合利华、宝洁、欧莱雅等50家头部客户，在重大营销战役中收获颇丰，国内斩获诸多奖项。还曾担任尼尔森大中华区媒介研究管理岗位，熟稔营销心理学，有敏锐的消费者洞察，并将其应用在零售行业中积累了大量丰富的实战经验。
