人工智能操作系统（AIOS）与软件安全论坛

专刊论坛 S6

一、论坛介绍

随着人工智能技术的快速发展与规模化应用，人工智能操作系统（Artificial Intelligence Operating System，AIOS）逐渐成为连接人工智能模型、计算资源与智能应用的重要基础软件平台。与传统操作系统叠加人工智能算法的模式不同，AIOS面向智能体运行与协同需求，将智能决策、多智能体协同、自然语言交互、AI任务调度以及多模态数据处理等能力融入系统架构，为智能软件和传统软件提供新的运行基础。

AIOS原生智能特性在提升系统智能化水平的同时，也带来了新的软件与系统安全问题，包括AIOS内核与智能调度安全、AI模型与操作系统融合安全、多智能体协同安全、软件漏洞检测与修复、软件供应链安全、智能体权限与能力治理、大语言模型驱动的软件安全防御等。

本论坛围绕"人工智能操作系统（AIOS）与软件安全"主题，邀请相关领域专家学者和论文作者开展交流，重点讨论AIOS自身安全、运行于AIOS环境中的软件安全以及二者交互过程中产生的跨层安全问题，分享相关理论、方法、技术及应用实践，促进人工智能操作系统与软件安全领域的学术交流与技术合作。

四、论坛特邀嘉宾

1. 报告人：张涛 教授

题目：AI赋能的软件可靠性与安全性研究：过去，现在，未来

摘要：软件可靠性与安全性已成为衡量软件质量的重要指标。在以往的研究中，学者们倾向于利用静态分析和机器学习等传统方法来解决这些问题。然而，这类方法无法深层次地捕捉源代码与软件制品上下文之间的语义关系。在这个新时代，生成式人工智能（Generative AI）可以通过深度分析自然语言与编程语言之间的语义关系，从而帮助开发者自动生成源代码、补丁、提交记录（commits）、代码注释以及对用户评论的回复。为了使软件的可靠性与安全性达到最佳性能，众多学者走过了一段漫长的探索之路。对于我们团队而言，我们最初是从依赖缺陷报告（bug reports）或用户评论信息来执行单一的自动化软件可靠性与安全性任务开始的。通过为缺陷报告建立统一的神经网络模型和统一的表征模型，我们构建了一套能够实现多种自动化软件可靠性与安全性任务的方法。在此过程中，我们发现了预训练语言模型在执行自动化软件可靠性与安全性任务时存在的"过度解读（over-interpretation）"问题，并提出了相应的缓解策略。沿着这一路径，依托大语言模型（LLMs）的强大能力，我们提出了一系列新模型及相应工具，以提升自动化软件可靠性与安全性任务的性能。从目前到未来若干年，我们计划把智能体AI（Agentic AI）与软件工程方法相结合，进一步增强AI系统的可解释性，从而使未来的自动化工具能够产生准确且具可解释性的结果。

简介：澳门科技大学计算机科学与工程学院教授。他是英国计算机学会会士、中国计算机学会杰出会员、ACM/IEEE高级会员，并担任IEEE 计算机学会澳门分会创始主席及 IEEE软件工程技术委员会（TCSE）会议主席。因其在计算领域的贡献，被IEEE计算机学会遴选为杰出访问学者（Distinguished Visitor）。张教授的主要研究方向是软件工程与软件安全，他在 ICSE、ESEC/FSE、ASE、TSE、TOSEM 等国际学术会议与期刊上发表了100余篇高水平论文。部分研究成果正在为华为和深水云科等企业赋能。在学术履历与服务方面，他现任软件工程领域顶级期刊 IEEE TSE 的副主编（Associate EiC），并兼任 IEEE TRel、JSS、EMSE 等多个权威国际期刊的编委。此外，张教授担任 ISSRE 2027、APSEC 2025、SANER 2023 等多个知名国际学术会议的大会主席，并长期担任 ICSE、FSE、ASE 等顶级会议的程序委员会委员，曾荣获 FSE'26、TOSEM、JSS、IST等期刊和会议所颁发的杰出审稿人奖。

2. 报告人：杜冬冬 副教授

题目：声明式智能体操作系统研究与实践

摘要：随着大语言模型、智能体等人工智能技术的快速发展，操作系统研究既面临新的挑战，也迎来了新的发展机遇。传统操作系统围绕命令式接口和人工编程构建，在开发、抽象、执行和扩展等方面逐渐难以满足智能体应用对自主开发、意图理解、高效探索和动态定制的需求。在开发范式方面，操作系统正在从人工专家主导的代码开发向规约驱动的模型生成演进；在系统抽象方面，需要从命令式接口演进到面向Intent的声明式接口；在运行机制方面，需要原生支持智能体高效探索与回滚；在系统扩展方面，需要支持多智能体场景下的动态内核定制与虚拟化扩展。报告将分享团队在 Declarative OS for Agents方向的思考与最新研究实践，及其关键技术，探讨面向 Agent 时代的新一代操作系统设计。

1. 报告人：伍复慧 副教授

题目：KylinX:双内核通用可信操作系统

摘要：针对通用操作系统在生态兼容与安全可信之间长期存在的结构性矛盾,本文提出并实现了 KylinX 双内核通用可信操作系统.该系统复用Linux内核承载应用与驱动生态,将度量、密钥、策略与审计等高价值安全能力收敛到独立可信内核,并由轻量级虚拟化监视器在更高特权级执行统一隔离裁决.围绕"职责分离、硬件强制隔离、受控跨域协作"三项设计原则,KylinX通过二阶段页表与IOMMU建立内存与DMA强边界,通过启动度量与运行时动态度量贯通可信链,并构建可信域与通用域之间可审计、可扩展的通信接口.基于飞腾 D3000M CPU的长城笔记本的系统评估表明,该架构在保持 Linux生态兼容和接口语义稳定的同时,实现了可接受的运行时开销：计算与内存路径影响较小,I/O场景影响有限.综合结果显示,KylinX在工程可部署性、生态可用性与系统可信性之间形成了可验证的平衡.

简介：伍复慧，博士，副教授，楚天学者。发表高水平论文20余篇，授权国家发明专利3项，出版教材1部。主持湖北省自然科学基金、湖北省高校优秀中青年创新团队、参与湖北省教育厅哲学社会科学研究、湖北省教学改革研究等项目10余项。

2. 报告人：徐刚 高级工程师

题目：事件驱动智能体操作系统跨层能力治理方法

摘要：事件驱动智能体操作系统中，事件来源、任务创建与工具执行跨越不同信任域，单点权限检查难以建立完整链路的授权依据。本文提出跨层能力治理方法 E2AG（Event-to-Agent Governance），通过来源契约与目标策略控制任务准入，以任务绑定的短期能力约束工具调用，并记录授权依赖以支持审计与失败定位。本文建立跨层授权状态模型，在 DiOS 原型中实现该方法，并开展消融、外部机制对照、端到端执行及故障注入实验。结果支持所测配置下跨层授权约束的有效性，表明任务准入与调用检查分别承担不可相互替代的治理职责。

简介：华东师范大学软件工程学院、国家可信嵌入式软件工程技术研究中心高级工程师。长期从事信息系统架构设计与智能系统研发，研究及应用方向涵盖智能制造优化调度、机器视觉和工业边缘计算。作为核心技术团队成员参与 MAPS 智能制造规划系统的研发与产业应用，近年来围绕大模型应用平台、智能体操作系统及安全治理开展研究与工程实践，参与 ChatECNU 平台建设及 DiOS 研发。

3. 报告人：周远 研究员

题目：面向智能制造操作系统的可信计算模型推荐:一种多智能体协同方法

摘要：智能制造操作系统(Intelligent Manufacturing Operating System,IMOS)的核心功能是智能制造业务计算:根据运行数据,选取或生成算法,实时监控生产状态,进行故障预测、质量控制和工艺优化.针对现有业务计算将控制逻辑与计算模型静态绑定,导致跨场景复用困难且缺乏系统性可信保障的问题,本文提出了一种面向IMOS的多智能体协同可信计算模型推荐方法.该方法以运行时模型动态推荐为核心,主要包含三个关键步骤:第一步,将控制逻辑(规则库)与计算模型(模型库)解耦分离,构建由任务解析、动作编排、种类匹配、实例调度和计算执行五类智能体组成的协同推荐框架,实现从任务需求到模型实例的动态决策;第二步,提出指令一致性感知与可信度评估机制,通过任务指令内部冲突识别以及模型适用性、来源与历史行为的综合评价,实现适用性与可信性的协同选择;第三步,提出异常根因驱动的可信反馈执行机制,通过运行状态监测与根因回溯,触发模型重调度或控制流重规划,形成计算模型推荐与实际运行行为之间的运行时自愈闭环.该方法通过解耦管理与动态关联,有效提高了计算功能的跨场景复用与适应能力,并从指令、模型和执行三个层面保障了智能计算的可信.实验结果验证了所提方法在跨场景计算模型推荐及可信保障方面的有效性.

简介：浙江理工大学研究员、博士生导师，国家级青年人才。研究领域为智能软件系统，包括自动驾驶系统、机器人系统、具身智能系统和智能制造系统。主持国家自然科学基金面上项目1项。发表论文60多篇，获ACM SIGSOFT杰出论文奖2次（ASE 2024、ISSTA 2026）、2024年世界机器人大会最佳论文提名奖、IEEE ISPA 2021最具创新奖等。曾担任CCF推荐会议复杂计算机系统工程国际会议（ICECCS 2025）程序委员会主席和2026年度第2期CCF软件工程专委会青年论坛执行主席。

题目：基于混合依赖关系矩阵制导的鸿蒙内核模糊测试

题目：基于消息特征差异分析的ROS应用程序模糊测试方法

摘要：机器人操作系统(Robot Operating System,ROS)是机器人软件开发的开源软件平台,基于其开发的应用程序为机器人提供感知、定位、规划和控制等核心功能,ROS应用程序的可靠性直接影响机器人的安全稳定运行.近年来,模糊测试因其具备自动化程度高、人工成本低和漏洞检测能力强等特点,成为ROS应用程序测试方法之一.然而,现有ROS应用程序模糊测试方法主要关注种子是否覆盖新的代码分支,或其消息特征是否在历史记录中出现过,较少关注种子的消息特征和历史消息特征记录之间的差异程度,导致部分对应稀有消息特征的种子难以及时获得变异机会,限制了测试效果.为此,本文提出了一种基于消息特征差异分析的ROS应用程序模糊测试方法RMFDA(ROS fuzzing based on Message Feature Difference Analysis).该方法在测试过程中将种子执行期间ROS节点间传递的消息提取为消息特征；随后计算种子的消息特征和历史记录之间的差异程度得到差异分数；最后结合种子的消息特征状态、变异次数和消息特征差异分数进行种子选择,优先选择更可能对应稀有消息特征的种子进行变异.实验表明,RMFDA在8个ROS应用程序上的总分支覆盖数量相较于ROFER和ROZZ分别提升了4.81%和21.58%,漏洞检测数量分别提升了21.74%和33.33%.此外,RMFDA检测到4个此前未被报告的漏洞,且均得到开发者确认.

题目：DiffHallu：基于差分测试的长文本生成幻觉风险量化方法

摘要：随着大语言模型（Large Language Model，LLM）在知识服务、内容生成等领域的广泛应用，其生成内容的可靠性问题日益受到关注。LLM可能生成与客观事实、给定上下文或可验证知识不一致的幻觉内容，并在高风险应用场景中带来安全隐患。长文本生成的输出空间开放，且通常包含多个相互关联的事实性陈述，难以为模型输出预先给定完备且唯一的正确结果，因而面临突出的测试预言问题。现有针对长文本生成的幻觉风险量化方法通常依赖高质量标注数据训练专用检测器，或借助外部知识资源验证生成内容，因而受到数据与知识资源的可用性限制。差分测试可通过比较差分对象在受控条件下的行为差异发现异常，但LLM生成的随机性和开放性使传统的输出一致性比较难以直接用于幻觉风险量化。针对上述问题，本文提出基于差分测试的长文本生成幻觉风险量化方法DiffHallu（Differential Testing for Long-form Hallucination Detection）。其无需针对幻觉风险量化任务额外训练专用检测器，在实际应用中不依赖外部知识库或人工参考答案。DiffHallu将LLM在相同对话前缀下生成的多个候选续写作为差分对象，使用语义聚类将候选续写归一化为语义簇，用以计算语义熵，以此量化候选续写的语义分散程度，进而估计LLM长文本生成输出的幻觉风险。在4个目标LLM和13,292个实体级实验样本上的实验结果表明，DiffHallu在幻觉风险量化任务上的平均AUROC为0.853，相比4种基线方法平均提高了7.8%~16.7%；在二元幻觉检测任务上的平均F1为0.873，相比4种基线方法平均提高了6.4%~7.8%，并在4个目标LLM上均取得最高的精确率和准确率。
