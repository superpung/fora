Rust与系统软件论坛

一、论坛介绍

随着现代计算系统规模与复杂度的快速增长，系统软件对安全性、可靠性与性能的要求愈发严苛。传统系统软件主要基于 C/C++ 等低层语言实现，但这些语言天然缺乏对内存安全、并发安全等保障，导致长期以来系统级漏洞频发。作为一门新兴的系统编程语言，Rust 通过所有权机制、借用检查与零成本抽象等设计，在保证高性能的基础上提供了强内存安全与并发安全保证。这使 Rust 成为构建下一代操作系统、编译器、网络系统、设备驱动等系统软件的重要候选语言。

本论坛旨在聚焦 Rust 在系统软件领域的研究前沿与工程实践，包括内核组件设计、系统库与运行时构建、程序分析与安全性评估、Rust 与现有生态互操作性挑战等主题。论坛将由来自顶尖高校与研究机构的专家学者主持，围绕 Rust 在体系结构级、操作系统级、软件工程级的核心问题展开深入研讨，分享最新研究成果与工业实践经验。

Rust 在系统软件领域的研究与应用不仅可以提升系统软件的安全性与质量，还能够引导语言设计与分析技术的发展，带动系统工程与编程语言、软件工程等交叉学科的融合。在国家倡导自主可控、安全可信软件基础设施建设的背景下，该论坛具有重要的学术推动意义和工程实践价值，是推动 Rust 与系统软件深度融合的重要平台，对培养相关领域人才、促进产业界与学术界交流均具有积极推动作用。

本论坛旨在为学术界与工业界的研究者及开发者提供一个交流平台，共同推动Rust在系统软件领域的可靠应用与理论发展。

四、论坛报告嘉宾简介

1. 报告人：张毅 vivo系统研发总监

题目：Rust筑牢底座，AI驱动未来：vivo蓝河操作系统的探索与实践

摘要：vivo蓝河操作系统的Rust全栈落地实践，探索AI时代操作系统研发之道。蓝河操作系统是vivo面向通用人工智能时代自主研发的智慧操作系统。本次演讲将深入介绍蓝河操作系统基于Rust语言实现全栈落地的架构设计思路和工程化实战经验，涵盖操作系统内核、Harness、图形、UI框架、工具链等关键技术的探索与成果。听众将了解Rust在操作系统全栈研发中的架构设计、工程实践与性能优化经验，并获得关于AI时代操作系统研发方向的思考与启示。

简介：张毅，vivo系统研发总监。拥有10多年的操作系统研发经验，负责vivo蓝河操作系统（BlueOS）的架构设计及研发工作。作为团队核心成员，长期专注于蓝河操作系统核心方向的技术架构设计和中长期规划，积极推动Rust语言在软硬件生态中的融合应用，并致力于促进蓝河操作系统技术与产业实践的结合。

2. 报告人：刘昱玮 博士 蚂蚁技术研究院助理研究员

题目：大模型驱动的 Rust 形式化验证：从证明生成到验证工程自动化

摘要：形式化验证能够为系统软件提供严格的正确性保障，但在真实软件仓库中，规约编写和证明构造仍需要大量人工投入。特别是对于 Rust 操作系统等复杂系统软件，跨模块依赖、项目特定的证明知识以及验证工具链的持续演进，使得大规模自动化验证面临诸多挑战。本报告将介绍 KVerus，一种面向仓库级 Rust 程序的大模型辅助形式化验证方法。KVerus 通过依赖感知的代码上下文构建、语义化证明知识检索以及验证器反馈驱动的迭代修复，实现复杂代码仓库中的自动化证明生成，并已在真实 Rust 操作系统 Asterinas 的验证实践中取得成效。在此基础上，报告还将介绍 KVerus 的后续改进，包括将验证能力封装为可组合的智能体 Skills、自动生成程序规约代码（Specification）与证明代码（Proof），以及通过验证器反馈精简冗余证明代码。最后，结合 Asterinas 的形式化验证仓库 VOSTD 的实际验证实践，探讨大模型辅助形式化验证从单一证明生成走向完整、可维护的验证工程自动化的机遇与挑战。

简介：刘昱玮，博士，蚂蚁技术研究院研究人员。2024 年获中国科学院大学软件工程博士学位，曾在蚂蚁科技集团博士后科研工作站与中国科学院软件研究所联合开展博士后研究。主要研究方向包括系统软件可靠性、漏洞挖掘、程序分析与形式化验证，近年来重点关注大语言模型驱动的系统软件分析、自动化测试与形式化验证技术。相关研究成果发表于 S&P、CCS、ICSE、ASE 等系统安全与软件工程领域国际学术会议。

3. 报告人：周睿 中级工程师

题目：内核界的"乐高"：用 Rust 组件按需拼装多形态内核

摘要：面向嵌入式、AI 边缘计算及智能体任务执行对轻量、高效、可裁剪内核的需求，TGOSKits 以 Rust 可复用组件为基础，支撑 Unikernel、Linux 兼容内核与 Hypervisor 等系统形态，通过编译期装配和清晰接口实现按需定制与跨系统复用。项目以单向依赖、能力接口和安全责任分层组织组件，收敛高风险操作与 unsafe 边界，并结合项目规则、领域技能和自动化验证，为人工与大模型提供职责明确、约束清晰的开发环境。本报告重点介绍其如何以可组合架构降低内核定制复杂度，以安全边界和工程约束降低人机协同开发风险。

简介：泉城省实验室工程师，TGOSKits 开源项目负责人，资深 Rust 开发者。主要研究方向包括操作系统内核、虚拟化、驱动框架及系统软件架构，长期活跃于 Rust 开源生态，具有丰富的底层系统研发与开源项目实践经验。

4. 报告人：饶子豪 复旦大学博士生

题目：基于安全属性的 Rust 程序验证

摘要：Rust 中 unsafe 操作的正确使用需要满足指针有效性、内存初始化、访问边界等安全条件。这些条件往往以自然语言描述，且涉及复杂的控制流程与对象状态变化，难以直接用于自动化验证。本报告围绕安全属性的表达、传播与检查，介绍基于安全属性的 Rust 程序验证方法。通过结构化建模将安全要求转化为可检查的规约，明确接口前置条件与类型不变量；结合程序依赖分析，追踪相关属性在函数调用和状态变化中的建立与保持；利用路径敏感分析与约束求解，检查程序实现是否满足安全契约。报告将结合标准库及开源项目中的典型案例，展示从属性规约到验证条件生成与检查的过程，并讨论方法的适用范围。此外，将探索接入大语言模型，辅助规约理解与验证结果分析。

简介：饶子豪，复旦大学计算机科学与技术专业博士研究生，研究方向为程序设计语言与软件工程，重点关注 Rust 程序安全、静态分析及人工智能辅助软件工程，开展安全属性建模、缺陷检测与自动化验证研究。曾获上海开源创新卓越成果奖特等奖、开放原子大赛 Rust 语言研究与创新应用赛一等奖。

5. 报告人：韩晓阳 南京大学博士生

题目：BrewFS：基于 Rust构建面向智能体协同的分布式文件系统

摘要：智能体在代码开发与数据处理过程中，常需要基于同一文件目录并行探索，同时保持各自修改相互隔离，并能在任务结束后进行审查和交付。传统基于工作区的隔离方式会带来额外的存储与初始化开销，共享可写目录则难以提供清晰的隔离和恢复边界。本报告探讨了智能体文件系统的负载特性，并介绍基于 Rust 构建的文件系统 BrewFS，重点讨论面向智能体工作区的分层设计、轻量化工作区设计和读写放大优化等。报告将介绍系统架构、关键设计权衡和当前验证进展，并讨论这类文件系统在智能体并行开发工作流中的适用范围。

简介：韩晓阳，南京大学计算机学院 2026 级博士研究生，关注 Rust 工程实践、系统软件和面向智能体的文件系统。参与旋武社区 Rust 课程建设，录制《From C++ to Rust》《Rust for FUSE》等课程，并担任开放原子校园行技术讲师。担任多个开源社区项目的 committer，相关项目累计 GitHub Stars 超过 1100。曾获开放原子旋武社区 2025 贡献奖。
