一、论坛介绍

本论坛聚焦"软件智能化开发、维护与安全"，围绕大语言模型、代码大模型和软件开发智能体在需求分析、架构设计、代码生成、测试验证、缺陷修复、软件维护、智能运维与安全治理中的应用与挑战展开交流。论坛也关注模型幻觉、生成代码漏洞、模型鲁棒性、智能体权限边界、行为审计、可验证与可追溯等问题，通过报告和圆桌讨论，促进软件工程、人工智能安全、网络安全与产业界交流，凝练可信软件开发的研究与实践路径。

四、论坛报告嘉宾简介

1. 报告人：李戈 北京大学博雅特聘教授

题目：基于大模型的软件自动化 – 进展与问题（V10.1）

摘要：当前，大语言模型与智能体技术迅速发展，软件开发的工具和模式正在发生变革。本报告讨论这两个互相关联的问题：当前基于大模型的软件开发智能体工作发展到了什么状态？其技术发展和产业应用中遇到了哪些问题？这些问题能否被解决以及有哪些潜在的解决方案？支撑智能体的大模型技术的能力边界在哪里？未来的智能化软件开发技术具有怎样的发展趋势或规律？对软件开发有何意义？以期引发大家的思考与讨论。本报告与11月8日"安全代码生成与软件可信构建"论坛的报告组合为上下篇，本报告为上篇。

简介：李戈，CCF杰出会员，CCF软件工程专委会副主任委员，北京大学博雅特聘教授，教育部长江学者。国际上"基于深度学习的程序理解与生成"研究的早期贡献者。迄今为止，发表相关论文200余篇，多项成果被国际学者认为是"首创性成果"并被广泛引用，所带领的研究团队在软件工程与人工智能领域的多项研究中保持领先状态。科研转化成果为航天、金融、IT领域的多家企业提供智能化研发支撑。

2. 报告人：狄鹏 昆仑芯 AI Infra 负责人、正高级工程师

题目：Agent 驱动的 XPU Kernel 生成与 Compiler IR 协同优化演进

摘要：传统编译器以编程语言为输入，通过编译器中间表示（IR）进行程序分析与优化，最终生成面向硬件的可执行代码。随着大模型与 Code Agent 的发展，Agent 开始具备理解程序、生成代码、分析编译错误、调用工具以及根据性能反馈迭代优化的能力。本报告以昆仑芯XPU Kernel Optimization 为切入点，探讨 Code Agent 如何协同编程语言、编译器 IR 与 Compiler，在"代码生成—IR变换—编译—执行—Profiling—反馈"的闭环中探索更大的优化空间。同时分析 Agent 在程序语义理解、IR 优化、硬件感知和自动搜索方面的能力边界，讨论 Agent 与 Compiler 的协同关系，以及从"编译器将程序转换为机器代码"走向"Agent 协同编程语言、IR 与 Compiler 自动探索高性能可执行程序"的可能路径。

简介：狄鹏博士，现任昆仑芯 AI Infra 负责人、正高级工程师，兼任新南威尔士大学副教授。在昆仑芯，他负责 AI Infra 建设，主导 XPU 编译器与系统软件研发。此前先后任职于华为与蚂蚁集团：在华为主导开发昇腾芯片 MindSpore 深度学习框架及 AKG 编译器；在蚂蚁集团带领智能平台工程团队，主导研发 CodeFuse、Ling-Coder-Lite 代码大模型及 OpenDeRisk 风险智能系统，相关成果获蚂蚁集团最高技术奖。他长期深耕编译器、程序分析、智能软件工程等领域，发表顶会顶刊论文数十篇，并担任中国科学院、清华大学、浙江大学等高校企业导师。

3. 报告人：王俊杰 中国科学院软件研究所研究员

题目：从轨迹分析到可靠驾驭：大模型智能体失效定位与能力提升

摘要：大模型智能体的失效往往并非源于显式的程序错误，而可能发生在任务理解、规划推理、工具调用或协作等多个环节，因此"失效发生在哪里、应如何修复"成为质量保障的核心难题。执行轨迹是探知智能体内部执行状态、还原其决策与行动过程的重要桥梁；但这类轨迹通常冗长、以自然语言和异构工具交互为主、内部推理又存在不可观测性，使得基于轨迹进行准确的失效归因与有效修复依然面临显著挑战。本报告将基于团队撰写的综述文章《LLM Agent Trajectory Analysis: From Failure Attribution to Enhancement》对大模型智能体轨迹分析领域进行介绍；同时也将介绍团队开展的研究工作，涉及失效定位基准TraceElephant，基于因果分析的失效定位方法CHIEF，基于轨迹分析的驾驭工程自动优化方法HarnessFix，基于变更历史经验提炼的Skill自演化方法VCE-Skill，以及面向工作流类型智能体的失效分析基准AgentFail和演化提升技术FlowFixer。

简介：王俊杰，中国科学院软件研究所研究员，博士生导师，智能博弈重点实验室副主任（主持工作）。中国科学院特聘研究岗位，青年创新促进会会员。主要从事智能化软件工程、软件质量、AI安全等方面的研究。在国际著名学术期刊/会议发表70余篇高水平学术论文，荣获ICSE、CHI、ICPC等会议的杰出论文奖、ACL领域主席亮点论文奖等。主持和参与了多项国家自然科学基金项目、科技部重点研发计划、CCF-华为胡杨林基金等。担任CCF A类期刊TSE的Associate Editor，ICSE、FSE、ISSRE等的PC member，TOSEM、EMSE、AUSE等期刊的审稿人。

4. 报告人：林云 上海交通大学副教授

题目：需求编译与约束工程

摘要：在生成式AI以前所未有的速度重塑代码生成的今天，软件工程正在从代码编写转向需求定义、行为约束与智能体协同开发，软件测试也由代码完成后的质量把关，前移为驱动需求澄清、架构生成和代码验证的核心机制。本次报告将结合教学改革、科研探索与系统原型，讨论智能体软件工程与场景测试技术的演进趋势。首先，报告将回顾在上海交大IEEE试点班开展的软件工程课程改革，介绍如何通过测试驱动开发、可执行需求描述和面向智能体的领域特定语言建模，引导学生从"代码工人"转型为"智能体架构师"，指挥多智能体复现12306等复杂业务。随后，报告将围绕需求可测试化与测试左移展开，介绍如何从需求验证意图生成项目特定测试，如何扩展用例以覆盖业务场景。在此基础上，报告将通过需求编译的可视化展示，呈现如何从复杂需求文档生成代码模块，并在需求、设计、测试与代码之间建立可查询、可回溯的追踪关系，使需求编译过程从黑箱生成走向可验证、可调试的工程流水线。进一步地，针对Web与移动端复杂交互中的规格理解、Oracle推断和应用特定缺陷发现问题，报告将介绍端到端GUI测试实践，并结合测试驱动的问题定位，剖析当前AI编程中的马太效应、幻觉与调试痛点，展望大模型在工业研发测试体系中的落地路径。

简介：林云, 上海交通大学计算机科学与技术系副教授，系副主任，博士生导师，原新加坡国立大学助理教授（研究岗），入选国家海外高层次青年人才计划、华为x-explore人才计划。研究方向包括自动编程、可解释AI、网络反诈等，获ICSE2018杰出论文奖，及多次中国软件大会原型研究奖。担任FSE'26 领域主席、ICSE、FSE、USENIX Security等重要国际会议的程序委员会委员。主持国家自然科学基金委海外优青项目及面上项目和多项校企合作。自动编程技术落地于豆包代码模型以及Trae IDE，GUI测试相关研究入选信通院优秀案例等。

5. 报告人：高翠芸 哈尔滨工业大学（深圳）教授

题目：迈向可信的软件智能：大模型驱动的代码审查

摘要：大语言模型正从代码生成工具演进为能够理解软件上下文、开展复杂推理并自主分析代码库的智能体。本报告将介绍我们在大模型推理与软件智能方面的近期探索。首先，介绍无监督推理方法 FREIA，利用自由能驱动奖励与自适应优势塑形，使模型在缺少标准答案时更好地平衡共识与探索。随后，结合代码审查、漏洞检测和静态分析等场景，探讨上下文建模、安全规格、仓库级探索及演化记忆如何提升模型的分析能力与可靠性。最后，总结大模型从通用推理走向真实软件工程应用所面临的关键挑战，并展望可信、自主、可持续演化的软件智能。

简介：高翠芸，哈尔滨工业大学（深圳）教授，哈工大青年拔尖人才。入选第九届中国科协青年人才托举工程，ACM TOSEM Associate Editor，获得2026 IEEE CS TCSE新星奖。主要研究领域包括：智能化软件工程和软件可靠性，近年来在相关领域的顶级会议和期刊如TSE、TOSEM、ICSE、FSE、ASE等上发表论文100余篇，荣获CCF A类会议ICSE 2025杰出论文奖、ICSE 2024杰出论文奖和ASE 2023杰出论文奖。

6. 报告人：吕晨 山东师范大学副教授

题目：可审计代码生成初探：从责任保持到有界修复

摘要：大模型驱动的代码智能体已经能够完成规划、编码、测试和修复，但程序通过测试并不能说明哪项生成决策应对哪部分代码负责，也难以据此确定后续修改的合理范围。在算法密集型、多阶段任务中，一项决策可能跨越多个代码区域，同一代码区域也可能同时承担多项算法责任。本报告围绕可审计代码生成，介绍如何在生成过程中建立决策记录、代码责任边界与外部验证证据之间的持续关联。重点讨论如何利用稳定责任标识关联生成承诺、代码责任归属、代码产物来源和验证证据，并据此开展责任定位与有界修复；最后简要介绍利用责任审计筛选执行轨迹，并据此训练代码智能体的初步探索。

简介：吕晨，山东师范大学计算机与人工智能学院副教授。主要从事智能化软件工程与软件安全研究，近期围绕可信代码生成中的效率优化、执行反馈利用和过程审计开展研究。相关成果发表于ICSE、FSE、ASE、ISSTA、EmSE等会议和期刊。主持国家自然科学基金项目及多项企事业合作项目，曾担任TOSEM、EmSE、ASE等期刊和会议的审稿人或程序委员会委员。

7. 报告人：徐悦甡 西安电子科技大学副教授

题目：FaaS系统运维中的资源治理：从函数服务到函数工作流

摘要：函数服务（FaaS）凭借高弹性和细粒度计费已成为云原生主流范式之一，但在复杂动态业务下，达到服务等级目标（SLO）与保障按需资源供给仍是智能化运维的核心挑战。本报告将分享课题组在FaaS资源治理方面的探索：在微观函数服务层面，针对负载波动与监控延迟导致的部分可观测问题，介绍基于深度循环强化学习的自适应弹性伸缩方法，实现多维指标协同优化与平滑调度；在宏观函数工作流层面，针对端到端性能与成本的权衡难题，介绍突破传统单一维度的CPU-内存协同供给框架，有效化解复杂拓扑下的配置寻优瓶颈。最后，总结从单函数运行时治理到工作流全局拓扑治理的演进思考，为Serverless软件工程与NoOps落地提供参考。

简介：徐悦甡，西安电子科技大学副教授、博士生导师，校软工学科智能软件工程方向秘书，省智能软件工程科技创新团队骨干，CCF系统软件专委会与软件工程专委会委员，一直从事智能软件工程、网络服务治理、系统软件运维等研究。发表领域内高水平论文80余篇，包括ICSE、FSE、WWW、ACM MM、IEEE TSE、IEEE TSC、IEEE TC、IEEE TII、IEEE TITS、IEEE IoT-J、IEEE TVT、ISSRE、ICSOC等，总引用超过3500次，5篇论文进入ESI高被引；出版专著《数智化教育技术与实践》。主持国自然基金面上/青年项目、省自然基金、国重/省重基金，多项国家重点研发计划子课题，以及航天软件系统运维项目、华为大模型专项等。获2023陕西省科技进步二等奖、CCF服务计算专委会青年学者激励计划等奖励；进入"2023年全球前2%顶尖科学家"；获得领域旗舰会议ICSOC 2025最佳论文提名奖与最佳系统原型奖。

8. 报告人：陈嘉弛 浙江大学百人计划研究员

题目：大模型辅助的低资源编程语言缺陷分析

摘要：随着大语言模型在代码理解与生成领域展现出强大能力，软件缺陷检测正在形成新的技术范式。然而，对于智能合约、Verilog等低资源编程语言，由于训练数据、漏洞样本和领域知识仍较为匮乏，通用大模型难以直接实现可靠的缺陷分析。本报告将介绍大模型与程序分析融合的低资源语言可靠性研究，围绕漏洞数据集自动构建、不可编译代码片段分析、自然语言描述与代码行为不一致检测、复杂项目级漏洞检测，以及安全知识增强的代码生成等问题，分享一系列缺陷定义、检测与验证方法。
