软件前沿技术导引论坛

学术论坛 R11

一、论坛介绍

大模型驱动的人工智能技术正深度重塑软件全生命周期，给传统软件工程、形式化程序分析、系统软件可信性研究带来全新机遇，同时也催生大量亟待解决的新问题。软件相关前沿技术迭代速度快、多学科交叉特征显著，不少师生与产业研发人员亟需一套体系化的知识导引，打通基础理论、技术方法与工程实践之间的认知鸿沟。

本论坛由中国计算机学会形式化方法专委会、软件工程专委会、系统软件专委会联合发起，定位为前沿技术导引，对标国际学术会议 Tutorial 模式，面向高校师生与产业界软件研发、研究人员，围绕程序验证、智能化软件工程、大模型软件评测、开源系统智能演化与安全保障等关键前沿方向开展分享。论坛不局限于单点成果汇报，重在系统梳理领域基础概念、核心技术方法、典型工程案例，剖析现有技术的能力边界，点明当下尚存的研究挑战，帮助参会者搭建完整的领域知识框架。

四、论坛报告嘉宾简介

1. 报告人：曹钦翔 长聘副教授

题目：验证复杂程序功能正确性

摘要：交互式定理证明是用于验证复杂程序的功能正确性的有力有段。报告人曹钦翔与上海交通大学团队在研发QCP（Qualified C Programming，https://www.qua.codes/）程序验证工具的过程中，在交互式定理证明框架中融入了符号执行、SMT求解、大语言模型等多种技术方法，提升程序验证的效率与自动化程度。报告中将介绍QCP工具的使用方法以及最新验证成果。现在，使用QCP验证的程序包括本科生算法数据结构课程内容、部分mini-gmp大整数运算库、miniSAT求解器等。

简介：副教授，上海市浦江人才，长期研究程序验证、程序逻辑与交互式定理证明，并研究人工智能技术在这些领域的应用。他2013年本科毕业于北京大学获得哲学（逻辑与科学哲学）学士学位获得数学双学士学位，于2018年在美国普林斯顿大学获得计算机博士学位。他在程序验证领域的代表性研究成果VST、VST-A验证工具是当时用于验证实际程序功能正确性的最好结果之一，他带领科研团队与合作者共同研发的QCP（Qualified C Programming）验证工具已将程序验证用于大量实际场景。曹钦翔的科研成果发表于TOPLAS、POPL、NSDI、OOPSLA、JAR、ICFP等国际一流会议与期刊，以及NeurIPS、ICML、ICLR等国际一流人工智能学术会议。2016年的哥德尔奖得主Peter O'Hearn曾评价他的工作"在具有挑战性的程序验证问题中获得了令人印象深刻的成果"。他参与发起了TPChina定理证明开放社区，他目前是中国计算机学会形式化方法专委会的执行委员。

2. 报告人：高翠芸 教授

题目：面向真实软件任务的大模型评测

摘要：随着大模型与编程智能体逐步应用于软件研发，如何在复杂上下文、多步骤推理与动态交互中可靠评估其实际能力，成为支撑技术落地的关键问题。本次分享将围绕数据集构建与评测框架设计，结合仓库级漏洞检测、细粒度代码审查和复杂交互网页生成等任务，介绍从真实项目数据采集、上下文补全、质量筛选到精细化标注的关键方法，并探讨如何通过任务分解、自动化执行与多维指标设计，评估模型的输出质量、定位能力及交互行为一致性。报告将提炼面向真实软件任务的评测方法，为开展模型选型、能力诊断与持续优化提供参考。

简介：高翠芸，哈尔滨工业大学（深圳）教授，哈工大青年拔尖人才。入选第九届中国科协青年人才托举工程，ACM TOSEM Associate Editor，获得2026 IEEE CS TCSE新星奖。主要研究领域包括：智能化软件工程和软件可靠性，近年来在相关领域的顶级会议和期刊如TSE、TOSEM、ICSE、FSE、ASE等上发表论文100余篇，荣获CCF A类会议ICSE 2025杰出论文奖、ICSE 2024杰出论文奖和ASE 2023杰出论文奖。

3. 报告人：王莹 教授

题目：鸿蒙软件的智能移植、演化与安全保障

摘要：本报告旨在探讨以大型语言模型为代表的智能软件工程技术在开源鸿蒙社区中的创新应用，聚焦于"一键式"安卓转鸿蒙应用的智能移植、演化与安全保障三个关键维度。随着开源鸿蒙生态的快速扩张，其在跨平台适配、版本迭代、安全合规等方面对传统软件工程方法提出了严峻挑战。本报告围绕大模型技术如何赋能鸿蒙生态的核心环节展开：首先，在智能移植层面，研究大模型在JS/TS、C/C++等关键语言跨平台软件移植与代码适配中的辅助作用，以提升开发效率与代码质量。其次，在演化层面，分析如何利用大模型理解OpenHarmony的版本演化历程，智能识别变更影响、优化依赖管理，并为兼容性维护提供决策支持。最后，在安全保障层面，重点探索结合大模型进行软件成分分析，以高效识别第三方库依赖及潜在许可证风险；同时，研究大模型在漏洞挖掘领域的应用，通过代码模式学习与智能分析，辅助发现系统潜在的安全缺陷。初步研究表明，智能软件工程技术为鸿蒙这类大规模、高复杂度的开源系统提供了创新解决方案，有望在自动化、智能化层面显著降低开发与维护成本，并增强系统的安全性与可靠性。

简介：王莹博士，东北大学软件学院教授，博士生导师。主要研究方向是开源软件供应链安全、鸿蒙软件智能迁移适配、具身智能。担任CCF系统软件专委执委、CCF软件工程专委会执委、CCF开源发展技术委员会执委。担任东北大学开源鸿蒙技术俱乐部主任；是中国计算机学会优秀博士论文提名奖、辽宁省优秀博士论文奖、微软亚洲研究院铸星计划、ACM SIGSOFT杰出论文奖（ICSE 2021、ESE/FSE2023）获得者、担任软件工程领域期刊IEEE Transactions on Software Engineering编委、ChinaSOFT 2023-2026软件工程女性学者论坛主席。是开源软件生态"依赖地域"问题、跨语言安全漏洞传播影响分析和开源鸿蒙软件供应链智能移植适配解决方案的最早提出者之一。多项软件缺陷检测与测试方面技术在微软、华为、龙芯中科、微众银行等企业落地应用。
