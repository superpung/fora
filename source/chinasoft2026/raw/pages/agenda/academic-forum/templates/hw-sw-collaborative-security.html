软硬件协同安全论坛

学术论坛 R32

一、论坛介绍

随着现代处理器推测执行、复杂缓存层次、异构加速器、可信执行环境以及软硬件接口持续演化，安全边界正由单一软件层或硬件层扩展到“处理器—系统软件—编译器—运行时”的跨层交互。传统分层防护难以全面覆盖微体系结构信息泄漏、权限边界绕过、硬件侧信道、xPU/AI基础设施安全等新型风险。本论坛聚焦处理器与芯片安全、硬件漏洞挖掘与验证、操作系统与虚拟化安全、xPU与AI基础设施安全以及软硬件协同防护等方向，邀请高校和科研院所专家交流最新研究进展与工程实践，探讨面向自主计算平台的安全分析、验证、检测与防护新范式，推动软件安全与硬件安全从“分层防护”向“跨层协同”演进。

2. 报告人：张新鹏（上海大学）

题目：从深度模型确权到AIGC溯源

摘要：随着AI技术的不断进步，大模型在不同领域展现出巨大的潜力，但同时也面临各种风险问题。一方面，大模型开发成本高昂，模型非法窃取与传播将严重损害模型持有者的正当权益。另一方面，利用AIGC技术生成逼真的虚假照片、视频和声音等信息可能被别有用心者用于操纵公众舆论、捏造虚假宣传、抹黑商业对手、诋毁个人名誉甚至实施精准欺诈。模型水印技术作为一种主动防御手段，近年来被广泛应用于深度模型的版权保护和生成内容溯源。本报告将介绍深度学习模型水印的发展历程，探讨判别式模型水印和生成式模型水印的核心问题和面临的挑战，展望AIGC水印的未来发展。

简介：国家杰出青年科学基金获得者，二级教授，上海大学计算机工程与科学学院院长。曾赴美国纽约州立大学宾汉顿分校、英国肯特大学访学，受德国洪堡基金会资助作为资深研究员赴德国康斯坦茨大学访学。主持国家自然科学基金重点项目、国家自然科学基金原创探索项目、国家重点研发计划、国家863计划等科研项目40余项。发表论文400余篇，被引20000余次，连续十二年入选“爱思唯尔”中国高被引学者榜单，并入选“科睿唯安”全球高被引科学家。申请发明专利30余项，授权近20项。以第一完成人获上海市自然科学奖一等奖，参与获得国家级教学成果二等奖两次。担任 IEEE Trans. on Information Forensics and Security （IEEE T-IFS）等国际学术期刊的 Associate Editor、ACM IH&MMSec与IEEE WIFS等国际学术会议的程序委员会主席和大会主席。

3. 报告人：金意儿（华为）

题目：机密Token：面向智能体的Token服务变革

摘要：随着大型语言模型基础能力的爆发式增长，人工智能的交互范式已经从单纯的对话式问答接口，演进为能够自主感知环境、调用外部工具、执行长周期复杂工作流的自主智能体。以OpenClaw为代表的Agent应用框架，通过集成模型上下文协议（Model Context Protocol, MCP）和丰富多样的插件技能（Skills），使得大模型能够直接与物理和数字基础设施进行交互。然而，这种深度耦合的交互模式和高度自治的执行权限，在极大提升生产力的同时，也导致系统攻击面急剧扩张，引发了前所未有的用户隐私泄露和系统级安全危机。为彻底阻断Agent应用场景下的上下文隐私泄露路径，必须从底层重构大模型推理的信任边界与数据流转机制。本报告基于此背景，提出并系统阐述一种全新的Token服务模式——机密Token。该技术理念不仅是对现有机密计算与密码学的工程创新，更是面向智能体的Token服务变革，帮助企业和个人更好地利用第三方算力资源而无需担心隐私泄露和合规问题。

简介：华为可信计算首席科学家，佛罗里达大学名誉教授，IEEE硬件安全与可信专委会联席主席。他的研究领域主要涉及软硬件协同安全和新兴集成电路安全，包括硬件支持的系统安全，集成电路产业链安全，以及可信自动化等。他撰写了《集成电路安全》一书，同时在国际知名期刊和杂志上发表了超过200篇论文，是亚洲硬件安全年会的联合创办人。他目前是IEEE设计自动化委员会的杰出讲师。他的论文获得了多项最佳论文奖，他本人也获得包括美国能源部和美国海军在内的多项杰出青年教授奖。

5. 报告人：袁斌（华中科技大学）

题目：面向复杂系统的逻辑漏洞高效检测

摘要：近年来，无人机、工业控制、云计算、智慧互联等关键领域的信息系统与软件中，逻辑漏洞频发，对关键信息基础设施安全构成严重威胁。与源于软件代码自身缺陷的固有安全漏洞不同，逻辑漏洞是一类与系统功能设计、业务流程实现等密切关联的缺陷，具有隐蔽性强、缺乏显著漏洞特征的特点。漏洞扫描、渗透测试等传统检测手段，因难以感知复杂语义、难以判别逻辑缺陷，对逻辑漏洞的检出能力明显不足。本报告拟从系统安全状态的准确刻画、语义引导的动态测试、AI辅助的漏洞高效识别等角度出发，探讨跨场景逻辑漏洞检测的通用方法，以期实现复杂系统中逻辑漏洞的自动化检测。

简介：袁斌，博士，华中科技大学网络空间安全学院副院长，长期从事漏洞检测、安全测试等方向的研究，发现无人机飞控系统、工业控制协议、物联网云平台、智能网联终端等系统与软件中影响上亿用户安全的多种安全威胁，获得CNVD/CVE漏洞编号70余项；获得中国电子学会科技进步二等奖、中国能源研究会能源创新奖技术创新二等奖、中国通信学会科学技术二等奖等科技奖励；在S&P、USENIX Security、CCS、TDSC、《中国科学：信息科学》等国内外顶级会议/期刊发表论文40余篇。

6. 报告人：马卓（西安电子科技大学）

题目：智能模型攻防及其安全应用

7. 报告人：孙彦斌（广州大学）

题目：面向加密勒索软件的多维欺骗防御技术

摘要：勒索攻击是当前网络安全领域最具挑战性的威胁之一，给全球带来了严重的经济损失。特别是随着RaaS模式及AI技术的发展，攻击者可借助商业化的勒索工具包或智能体更加高效地发动攻击，进一步加快了勒索软件的传播速度，提升了其复杂性和破坏力，加剧了整个网络空间的安全形势。本报告从勒索软件行为分析出发，研究面向勒索攻击防护的多种欺骗诱导技术，构建多类型系统“绊线”，实现对勒索攻击的快速、精准识别。同时，结合底线保护机制与协同防御策略，实现对勒索攻击的先期感知与有效阻断。

简介：广州大学教授，网安学院副院长，国家青年人才、国家创新人才。广东省工业控制系统攻防对抗重点实验室常务副主任。深耕网络攻防、工控安全方向，在国内外重要学术期刊、会议上发表论文100余篇。主持国家科技重大专项课题、国家重点研发计划课题、国家自然科学基金联合基金重点支持项目等20余项。相关成果获江西省科技进步一等奖、广东省哲学社会科学优秀成果奖二等奖、中国电子学会科技进步一等奖等3项，多次参加国家重保任务并获致函感谢。

8. 报告人：何家骥（天津大学）

题目：感知即泄露：MacBook内置IMU的软硬件跨层侧信道

摘要：软硬件深度一体化终端内置大量系统私有传感器与驱动接口，脱离常规 API 和权限管控，造成硬件感知与软件访问控制脱节，催生跨层攻击面。本研究以 Apple Silicon 版 MacBook 为对象，发现机身 IMU 可被普通应用通过未公开驱动直接读取，无需高权限和用户授权；击键会在振动信号中留下稳定物理特征。团队据此构建侧信道攻击框架：利用系统元数据确定击键时间，从振动信息还原密码、文本，还可区分用户与设备放置环境，模型对未知用户、设备依然奏效；相关漏洞已提交苹果并得到确认。最后，报告将探讨私有硬件接口访问控制与传感器安全治理，为物理感知、驱动与应用权限一体化的跨层防护提供参考。

简介：天津大学教授、博导，院长助理，国家重点研发计划青年科学家项目首席，天津市宝坻区A类人才，江苏省盐城市“黄海明珠”人才，清华大学博士后，IEEE会员，CCF会员，中国计算机学会网络与系统安全专委会执行委员（首批），中国密码学会密码芯片专委会委员，天津市企业科技特派员、“科技副总”。主要研究领域为数字集成电路（全流程）设计、处理器漏洞挖掘、硬件形式化验证、密码芯片设计与安全分析。
